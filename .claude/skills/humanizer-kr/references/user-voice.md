# User voice notes

Use this as a light preference only when the user asks for their own voice. The profile is based on a small, read-only sample of notes in the user's Mathematics vault, including personal notes on simple linear regression, set systems and measures, and Bayes' rule. Those notes are mostly technical study notes, so they do not define how the user wants every genre to sound.

## Observed tendencies

- Start with the idea or question directly, then explain why it follows. Avoid ceremonial openings and generic scene-setting.
- Explain relationships in a conversational, step-by-step way. Phrases like “여기서 주의할 점은”, “이렇게 두면”, and “따라서” fit when they make the reasoning easier to follow; do not add them mechanically.
- Mix Korean explanations with English technical terms when the English term is the standard or more precise label. Keep terminology consistent within a passage.
- Use compact headings, short paragraphs, equations or lists when they help organize technical material.
- Occasional questions, parenthetical clarifications, and emphatic notes appear in the study notes. Use them sparingly when they serve the reader.

## Guardrails

- Treat this as a preference, not a template. Do not copy sentences, mathematical content, mistakes, or the notes' exact structure.
- Preserve the requested genre and register. In particular, for coursework, follow the exam prompt, lecture definitions, evidence requirements, and any required formal style before applying this profile.
- Do not imitate typos, accidental grammar errors, inconsistent notation, or rough fragments. Preserve directness while making the prose clear.
- If the user provides a writing sample for the current task, use that sample over this limited profile.
