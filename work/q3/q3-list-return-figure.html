Q3 선택안 B · 대화창 상단 '대화목록' 버튼

겹친 창 사이에서 가려진 대화목록을 지금 보는 대화창의 버튼으로 앞으로 가져오는 과정

1불편 장면: 목록은 열려 있지만 다른 창들 뒤에 가려짐

2'친구 나' 창의 대화목록 버튼 → 목록 하나만 앞으로

3목록에서 '친구 가' 선택 → 해당 대화창이 앞으로

모의 화면·가상 대화. 창 배치와 '다른 앱 창'은 예시이며, 실제 카카오톡이나 macOS의 창 동작을 구현·측정한 것이 아니다. 목록이 닫혀 있을 때도 같은 버튼으로 복원한다(모형의 '목록을 닫은 상태로' 조작에서 확인 가능).
