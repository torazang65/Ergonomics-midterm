# Q3 작업 지시

## 읽을 자료

시험지 p.9-11, 실제 확보한 evidence/q3/observation.md와 사진·스케치, 소개 p.25·27·51-53, 연구방법론 p.21-32, 래더링·CJM p.17-18, 관찰 후 선택한 관련 인간공학 이론.

## 현재 할 일·산출물

1. 시험 기간에 직접 관찰·체험하고 evidence에 사실 기록.
2. process.md에 페르소나·페인 포인트와 근거 연결.
3. 원인 후보를 비교하고 HMW 질문과 대안 2개 이상 도출.
4. 효과·실현 가능성·새 부담·검증 가능성으로 최종 대안 선택 후 프로토타입 구성.
5. 테스트 요구 확인. 수행한 테스트와 제안 계획을 구분.

## 완료 기준

- 실제 관찰 증거와 교재/강의 원리의 연결을 명시.
- 공감·문제 정의·아이디어·프로토타입 항목 충족.
- 테스트 지표·과업·조건·절차를 기록하고 미수행 결과를 만들어 쓰지 않는다.
