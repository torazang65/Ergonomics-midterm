## 자료 취급과 남은 확인

- PNG·PDF 원본은 변경하지 않았다. PDF 렌더링 이미지는 `tmp/pdfs/q1-d/`에 별도로 생성했다.
- 현재 자료는 한 과업의 표시 결과다. 서비스·모델의 일반적 품질이나 인지부하·오류율의 차이를 측정한 자료가 아니다.
- 앱·웹과 저장 방식이 다르므로 표시의 존재·정보 배열은 비교하되, 물리적 글자 크기·시야 점유·가독성 우열·스크롤 비용은 현재 자료만으로 비교하지 않는다.
- 추가 관찰이 필요하면 같은 기기·비슷한 화면 폭에서 표 이동·읽기, 이전 조건 재탐색을 기록한다. GPT 체크리스트의 클릭 동작은 비교·추가 확인 대상에서 제외한다. 아직 수행하지 않은 항목은 결과를 채우지 않는다.
