# 문제 2 답안

## (a) 적중률, 오경보율, 민감도와 반응 기준

등분산 정규분포를 가정했다. 적중률은 실제 감염자 중 양성 판정 비율, 오경보율은 실제 비감염자 중 양성 판정 비율이다. 민감도는 \(d'=Z(H)-Z(FA)\), 반응 기준은 기준점에서 신호 분포와 잡음 분포의 밀도비 \(\beta=\phi(Z(H))/\phi(Z(FA))\)로 계산했다. \(d'\)가 클수록 두 분포가 잘 분리되고, \(\beta>1\)은 보수적 기준, \(\beta<1\)은 자유로운(모험적) 기준을 뜻한다(「3장 보충 2026.pdf」 PDF p.26, 31, 38, 47).

| 항목 | 진단기 A | 진단기 B |
|---|---:|---:|
| 적중률 \(P(H)\) | \(160/200=0.80\) | \(180/200=0.90\) |
| 오경보율 \(P(FA)\) | \(80/800=0.10\) | \(120/800=0.15\) |
| 누락률 \(P(M)\) / 정기각률 \(P(CR)\) | 0.20 / 0.90 | 0.10 / 0.85 |
| \(Z(H)\) / \(Z(FA)\) | 0.8416 / −1.2816 | 1.2816 / −1.0364 |
| 민감도 \(d'\) | **2.123** | **2.318** |
| 반응 기준 \(\beta\) | **1.595** | **0.753** |
| 판정 성향 | 보수적 | 자유로운(모험적) |

예를 들어 A는 \(d'=0.8416-(-1.2816)=2.123\), \(\beta=0.2800/0.1755=1.595\)다. B는 \(d'=1.2816-(-1.0364)=2.318\), \(\beta=0.1755/0.2332=0.753\)다.

## (b) 의사결정 특성과 누락·오경보의 절충

이 자료에서는 B의 민감도 \(d'\)가 A보다 높아 감염자와 비감염자를 더 잘 구분한다. 반면 A는 \(\beta>1\)인 보수적 기준을, B는 \(\beta<1\)인 자유로운 기준을 사용한다. 즉 B는 더 쉽게 양성 판정을 내린다.

| 오류 | 진단기 A | 진단기 B |
|---|---:|---:|
| 누락 | 40명 | 20명 |
| 오경보 | 80명 | 120명 |
| 전체 오류 | **120건** | **140건** |

B는 A보다 누락을 20명 줄였지만 오경보가 40명 늘어, 이 표본에서는 전체 오류가 더 많다. 따라서 B의 변별력이 더 높다는 판단과 현재 판정 기준이 적절한지는 구분해야 한다. 등분산 모형의 ROC 관계에 따르면, 더 큰 \(d'\)는 같은 오경보율에서 더 높은 적중률을 낼 수 있는 특성과 연결된다(「3장 보충 2026.pdf」 PDF p.45–47). 다만 이는 기준을 조정했을 때의 모형상 기대이지, 이 시험 자료에서 직접 확인한 결과는 아니다.

이 자료의 감염 유병률은 20%다. 비용과 보상을 반영하지 않고 오류 수를 최소화하는 강의의 기준은 \(\beta_{opt}=P(N)/P(S)=800/200=4\)다(「3장 보충 2026.pdf」 PDF p.40). 두 진단기 모두 이보다 자유로운 기준을 보이며, B가 A보다 더 자유롭다. A의 전체 오류가 이 자료에서 더 적은 결과는 A의 기준이 \(\beta_{opt}\)에 더 가까운 점과 부합한다. 다만 실제 누락·오경보 비용과 보상값이 제시되지 않았으므로 비용을 반영한 최적 기준을 정할 수는 없다. 강의의 비용 모형에서는 오경보 비용이 커질수록 \(\beta\)가 커지고, 누락 비용이 커질수록 \(\beta\)가 작아진다(같은 파일 PDF p.19).

팬데믹 상황에서 누락된 감염자는 음성 판정을 믿고 격리 없이 생활해 추가 전파로 이어질 수 있다. 반면 오경보가 늘면 불필요한 격리와 확진검사 수요, 의료진과 검사 자원의 부담이 커진다. 따라서 적절한 기준은 유행 단계와 유병률, 검사·격리 여력, 오류별 비용에 따라 달라진다. 누락을 줄이는 방향으로 기준을 조정한다면, 양성 판정에 확인 검사를 연결해 오경보의 부담을 관리하는 방안도 함께 고려할 수 있다.

## (c) 정보량, 소음·애매성의 의미와 개선 방안

행은 실제 상태 \(X\), 열은 시스템 표시 \(Y\)로 두었다. 결합 빈도를 확률로 바꾸고 log₂를 사용해 bit 단위로 계산했다(시험지 「2026 midterm.pdf」 PDF p.7–8; 「3장 보충 2026.pdf」 PDF p.50, 55–59).

\[
H(U)=-\sum_u p(u)\log_2 p(u), \qquad
T(X,Y)=H(X)+H(Y)-H(X,Y)
\]

\[
\text{소음 }H(Y|X)=H(X,Y)-H(X), \qquad
\text{손실·애매성 }H(X|Y)=H(X,Y)-H(Y)
\]

| 정보량(bit) | 진단기 A | 진단기 B |
|---|---:|---:|
| \(H(X)\) | 1.485 | 1.485 |
| \(H(Y)\) | 1.485 | 1.539 |
| \(H(X,Y)\) | 2.122 | 2.182 |
| 전달 정보 \(T(X,Y)\) | **0.849** | **0.843** |
| 소음 \(H(Y\mid X)\) | **0.636** | **0.697** |
| 손실·애매성 \(H(X\mid Y)\) | **0.636** | **0.643** |

두 진단기의 전달 정보량은 거의 같다. 그러나 소음은 B가 더 크고, 애매성은 두 진단기가 비슷하다. 이 값들은 행렬 전체의 불확실성을 나타내므로, 정보량만으로 오류의 임상적 심각성을 판단할 수는 없다.

**소음**은 실제 상태를 알더라도 출력 표시가 불확실한 정도다. 강의에서는 전달된 정보에 포함되지 않은 채 체계 안팎에서 생겨 출력에 더해지는 정보로 설명한다(「3장 보충 2026.pdf」 PDF p.59). 행렬을 보면 A는 실제 경증 30명 중 10명이 음성으로, B는 실제 경증 30명 중 15명이 중증으로 표시됐다. 공중보건 측면에서는 이런 표시 오류가 귀가·격리·입원 판단과 자원 배분을 흔들 수 있다. 인간공학 측면에서는 실제 상태가 같아도 표시가 달라져 의료진이 결과를 예측하고 믿기 어려워지고, 추가 확인 부담이 생긴다.

**손실·애매성**은 표시를 알더라도 실제 상태를 확정하기 어려운 정도다. 강의에서는 의도한 입력 정보 중 일부가 체계 밖으로 빠져나간 양으로 설명한다(같은 파일 PDF p.59). A의 음성 표시 50건 중 10건은 실제 경증이고, 경증 표시 30건 중 10건은 실제 음성이다. B의 중증 표시 30건 중 15건은 실제 경증이며, 실제 중증 20명 중 5명은 경증으로 표시됐다. 공중보건 측면에서 A의 음성 표시는 감염자를 놓칠 위험이 있고, B의 중증 표시는 자원 과배정과 일부 중증 환자의 치료 지연 위험이 있다. 인간공학 측면에서는 표시만으로 실제 상태를 판단하기 어려워져 의료진의 판단 부담과 오류 가능성이 커진다.

**개선 방안**은 감지 성능, 판정 기준, 표시를 이용한 후속 조치를 나누어 설계해야 한다. 먼저 시험지가 100명 행렬의 오류 원인으로 제시한 센서 오차와 신호 감쇄에 대해 센서 보정, 약한 신호의 재측정과 감쇄 보상을 검토한다(시험지 PDF p.7). 이 자료에서 A의 \(d'\)가 B보다 낮지만, 센서 오차가 그 차이의 원인인지는 확인되지 않았다. 신호와 잡음의 겹침을 줄이는 방향으로 개선한 뒤, 새 표본에서 \(P(H)\), \(P(FA)\), \(d'\)와 3범주 오차 행렬을 다시 측정해 효과와 셀별 변화를 확인해야 한다(「3장 보충 2026.pdf」 PDF p.43, 48).

판정 기준은 오류 비용에 맞춰 조정한다. 1,000명 이진 판정 자료에서 B는 A보다 누락이 20명 적지만 오경보가 40명 많다. 누락으로 인한 전파 위험이 큰 상황에서는 자유로운 기준을 검토할 수 있고, 확진검사·격리 자원이 부족하면 늘어나는 오경보의 부담도 함께 계산해야 한다. 기준만 바꾸면 적중률과 오경보율이 함께 변하므로, 비용·유병률·검사 여력을 정한 뒤 두 비율을 함께 평가한다(「3장 보충 2026.pdf」 PDF p.19, 40, 45–46). 양성 결과에는 확인 검사를 연결하고, A처럼 누락 위험이 있는 음성 결과는 증상이나 노출력이 있는 경우 재검하도록 하는 방안을 검토할 수 있다.

100명 3범주 행렬에서는 오류가 몰린 **경계마다** 후속 확인을 다르게 둔다. A의 경증→음성 10건은 음성 표시만 믿고 귀가시키지 않도록 할 이유가 된다. B는 경증→중증 15건과 중증→경증 5건이 함께 있으므로, 중증 판정 기준을 한쪽으로 옮기기만 하면 다른 방향의 오류가 늘 수 있다. 중증도 결정 전 보조 임상 정보나 재검 결과를 확인하는 절차를 검토한다. 센서나 판정 로직을 바꾼 뒤에는 두 오류 셀과 소음·애매성을 재측정하고, 후속 확인 절차는 의료진의 최종 결정 오류를 별도로 평가해야 한다. 두 진단기의 전달 정보량이 비슷하다는 사실만으로 위험이 큰 셀의 개선 여부를 판단할 수 없다(「3장 보충 2026.pdf」 PDF p.59).

표시 혼동은 시험 자료에서 확인된 원인이 아니다. 현장 평가에서 혼동이 발견되면 범주별 문자와 심볼의 의미를 일관되게 유지하고 색을 더하는 방안을 시험할 수 있다(「6장 디스플레이 보충 2026.pdf」 PDF p.33–35). 코드 조합이 항상 유리한 것은 아니므로, 표시 변경 전후에 의료진이 범주를 잘못 읽는 비율을 비교해 채택 여부를 정한다. 이진 판정 1,000명 자료와 3범주 100명 행렬은 별도 평가이므로 각각의 오류 건수를 합산하지 않는다.
